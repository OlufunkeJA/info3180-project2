## Setup Instructions

### Start Flask API
```bash
$ python -m venv venv (you may need to use python3 instead)
$ source venv/bin/activate (or .\venv\Scripts\activate on Windows)
$ pip install -r requirements.txt
$ flask --app app --debug run
```

## API Documentation

```sh
npm install
```

## Deployed Application URL
```sh
npm run dev
```
